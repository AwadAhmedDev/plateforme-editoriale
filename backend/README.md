# Backend

## Stack

- Node.js
- Express.js
- TypeScript
- JWT
- Multer
- MySQL

## Architecture

src/

- config
- routes
- controllers
- services
- repositories
- models
- middlewares
- validators
- utils
- types

## Commands

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build project:

```bash
npm run build
```

Start production server:

```bash
npm start
```
