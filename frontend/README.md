# Frontend

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form
- Zod

## Architecture

src/

- app
- components
- features
- hooks
- services
- schemas
- types
- constants

## Commands

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build project:

```bash
npm run build
```

## Objectives

- Responsive UI
- Accessibility
- SEO
- Reusable components
- Type safety
